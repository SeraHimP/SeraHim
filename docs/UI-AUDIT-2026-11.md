## 二、待议（UI 重构讨论用）

按"同一类问题一种解法"归并。每条写现象 + 我的建议，具体长什么样等你定。

### A. 窗口骨架不统一
1. **地图编辑器**是唯一没有左侧导航的大窗口：一长条纵向堆叠（起点地图 → 编辑工具 → 画布在折叠线以下），
   原生白底下拉框，标题里还带括号说明。建议改成与模板编辑器同一骨架：左侧"地形 / 建筑 / 路径 / 配置"，右侧画布 + 工具。
2. **窗口尺寸三种**：设置/添加单位/模式 620px，模板编辑器 880px，地图编辑器更宽。建议统一成两档（单页小窗 / 带导航的大窗）。
3. 模板编辑器标题下面紧贴一行小灰字"单位模板"（导航分组标题），和标题挤在一起。

### B. 一屏里胶囊按钮太多（模板编辑器属性页最典型）
一屏最多四行胶囊：页签（属性/武器/被动/初始状态/龙魂）→ 阵营（共享/仅蓝/仅红）→ 应用范围（仅模板/仅场上/模板+场上）
→ 属性分组（核心/攻击/防御/穿透/特效/法力/其他），下面再跟一行重复已选状态的"阵营：双方共享 ｜ 应用范围：……"。
建议：阵营 + 应用范围收进页脚"应用"按钮旁的一个下拉（它们只在提交时才有意义）；属性分组改成同一页里的分节标题，不再做成页签。

### C. 按钮与文案风格不一致
1. 页脚：设置窗口是"✅ 应用设置 / 确定 / 取消"，模板编辑器是"💾 保存 / 📂 打开 / 📋 JSON / 应用 → … / 关闭"，
   添加单位是"+ 加入清单 / 🚀 批量生成 / 关闭"。有的带 emoji、有的不带；"关闭"和"取消"混用。
   建议：页脚按钮一律不带 emoji，主操作用强调色；有回滚语义的叫"取消"，没有的叫"关闭"（规范第三节已有判据）。
2. 开关的写法有三种：胶囊高亮、"已开启（点击关闭）"文字按钮、"✅/⛔ + 图标 + 名字"。建议统一成一种开关控件。
3. 设置"防御塔无敌/停火"三个按钮写成"全部关 / 🔵 关 / 🔴 关"，读不出当前状态是开是关。

### D. 信息呈现
1. **天气页**（Q15 会整体重写）：预报条左侧一块纯黑、没有图例和刻度；"基础天气"那排"+43% ●"读不出含义；占比显示到小数点后一位。
2. **技能数值页**：39 个技能一字排开、没有分组和搜索，找一个参数要滚很久。建议按兵种/塔分组 + 顶部搜索框。
3. **批量加技能**：矩阵表头只有两个颜色圆点，没有"蓝方/红方"文字；每一行末尾都有"全选"，与分组行的"全选"重复。
4. **出兵编排**：兵种开关写成"✅ + 图标 + 名字"，图标和勾选框挤在一起，一屏两行很花。
5. **生命统计窗口**（Q8）：内容单薄，见方案稿。

## 三、建议的推进顺序
1. 先定 A（骨架）与 C（按钮/开关/文案规则）——这两条定了，后面每个窗口照着改就不会再长歪。
2. 再按"最常开的先改"：模板编辑器（B）→ 天气（Q15）→ 设置 → 添加单位 → 地图编辑器。
