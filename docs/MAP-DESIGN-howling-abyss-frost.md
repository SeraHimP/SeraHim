## 1. 目标与范围

用户原话整理：嚎哭深渊重做成冰封风格。除了一座桥之外，其余地方是水/浮冰/
冰川/孤灵小岛（**幽灵/亡灵主题**，已用 AskUserQuestion 确认——呼应"嚎哭"这个
地图名，装饰走墓碑/幽蓝鬼火/飘散灵魂光点这类）。桥上被雪覆盖，但**保留缺口**；
桥两侧有石墙；石墙上加火炬，最好带火焰特效；光源目前可以不加（等塔光照整体
方案定了再说），如果有把握做也可以做。

范围边界（不重新论证，直接抄第 4/5 节已经定的规则）：
- **原图 `howling_abyss.js`（`howling_abyss_v1`）完全不动**，新建一张风格化副本，
  与 `demo_stylized_v1` 相对于三张老地图的关系完全一样。
- 不碰仿真层——这次是纯视觉工作，`isWalkable`/寻路/索敌/弹道等判定逻辑
  **零改动**，包括下面第 4 节要讲的"缺口"。
- 不做高低差（`HA_TERRAIN.highground: {}`，本图定稿"无高低差"，这次不推翻）。
- 光源：默认先不加真动态光源（见第 3.4 节的理由），除非确认要提前做。

## 2. 现状勘查（动手前必须先弄清楚的事，第 4.3 节要求过）

读了 `src/data/maps/howling_abyss.js` 全文和相关渲染代码，几条关键事实：

1. **这张图是 navgrid 驱动的，不是走廊模型**——`useNavgrid: true` + `HA_NAVGRID`
   位图，桥的形状是从真实小地图逐像素描出来的（笔直桥、中段窄两端宽），不是
   `demo_stylized_v1` 那种"折线+半宽"的走廊模型。这一点很重要，下面第 3 节
   会说明它导致现有的风格化渲染代码**目前还不支持这张图**，需要先补代码
   （不是纯换配色就能跑）。
2. **"桥上的缺口"已经是现有数据的一部分**——`HA_TERRAIN.obstacles` 数组，13 个
   弧长位置 × 桥两侧共 26 个障碍物，效果是"每隔一段把桥面掐窄一次"，对应小
   地图上那排棕色方块。**这就是用户说的"保留缺口"**——不是要新增什么，是这次
   重做视觉时**不能删掉/改动这份数据**，只需要给它配一套跟"石墙"风格匹配的
   视觉表现（见 3.2 节）。
3. **本图没有河道**（`walls: { river: false }`）、**没有高低差**（`highground: {}`）
   ——这两条这次都不推翻。
4. **本图没有基地圈走廊模型**，蓝红双方各自的"基地"是桥两端天然变宽的那一截
   （navgrid 里描出来的形状），不是额外画的圆。

## 3. 视觉设计方案

### 3.1 桥面：雪覆盖 + 保留缺口

桥面（现在 navgrid 里 `walk=1` 的区域）改成雪白色调，替换现有导航贴图分支
（见 4.1 节）里写死的路面色 `#2b3647`。缺口（`obstacles` 数组的 26 个点）
在视觉上表现为**贴着桥沿的小块尖角冰岩**（呼应"石墙"材质，不是雪堆——雪堆
看不出"障碍"的实体感），大小与 `obstacles` 里声明的 `r: 26` 半径对应，摆在
数据本来的位置上，不额外挪动。

### 3.2 石墙：桥两侧

沿桥的可走边界（navgrid 的 walk/不可走分界线）生成一圈"墙体"——但**只是一条
贴边的窄带**，不是把桥外全部区域都抬成台地（那是现有非风格化 `WallLayer` 的
行为，会把整张图变成一个大平台，不是"桥两侧有墙、桥外是水面"的观感）。技术
方案见第 4.2 节，这是这次唯一需要新增渲染逻辑（不是配置调整）的地方。

墙体材质：低多边形石块观感（复用现有 `WallLayer` 崖面的"碎块阶梯边"处理方式，
换一套偏冷灰白的配色，接雪/霜的顶面）。

### 3.3 火炬：石墙顶部

沿两侧墙体等间隔摆放。位置建议复用现有 `obstacles` 用的等间隔弧长序列
`[280, 440, 600, 760, 920, 1080, 1240, 1400, 1560, 1720, 1880, 2040, 2180]`
中的一部分（比如每隔一个取一次，约 6~7 座每侧，密度上比"每个缺口都放"稀疏，
效果更像"重点节点点灯"而不是"墙头插满"）——具体取哪几个到时候看效果调，
不是这次要锁死的数字。

**火焰特效**：emissive 材质 + 一小簇火焰几何（不追求逼真，风格化路线一贯做法）
+ Bloom 辉光。**这里有一个必须先处理的依赖**：第 1 节记录过的描边 bug 根因是
"线/点类 FX 几何没有排除出预渲染相机"——如果火焰特效用 `Points`/`LineSegments`
实现火星/火苗，从一开始就要把它纳入 `HUD_SPRITE_LAYER`（或它的扩展），不能等
描边真正修复那天才补，否则这批新加的火炬会立刻重演"雨变粗黑线"那个问题
（现在描边默认是关的，不会立刻炸，但迟早要开，提前做对成本更低）。

### 3.4 光源：这次先不加真动态光源（可撤销的保守选择）

用户明确把这个决定权交给了我（"你要是有把握做也行"）。技术上确实有把握做
（现成的固定大小光源池机制、`3.5`/`4.4` 节已经写过方案），但这次先不做，理由：

- 塔夜间光照重做（3.5 节）的具体分级方案还没最终拍板；如果环境火炬现在先按
  某一套方案接了真灯，后面塔光照定案后可能要跟着返工。
- 这张图目前是"探路"性质的第一张风格化老地图重做，先把造型/配色跑通、拿到
  用户反馈更重要，光照可以作为独立的小快跑（fast follow）随后补。

**如果你希望这次就把火炬做成真的会照亮地面**，跟我说一声，我按 3.5 节"少数
重要节点才配真光源"的分级方式做（这张图可以全部火炬都配，因为总数不多，
不会碰到光源池数量上限）——这条改动量不大，可以随时加回来，不影响其它部分。

### 3.5 剩余区域：水 / 浮冰 / 冰川 / 孤灵小岛（幽灵主题）

这些都落在 navgrid 判定的"不可走"区域里，**纯装饰，不改变任何占位判定**。

- **水/冰面基底**：这次**不采用**第 4.5 节设想的"线段式极简水流"——那是给
  真正流动的河/湖用的，嚎哭深渊是冰封静态水面，没有"流动"这个语义，做成
  流动线段反而不对。改成一片接近静止的浅蓝白冰面（材质层面可以比现有
  `WaterLayer` 简化，不需要法线贴图滚动 UV 那套"讲究"的实现——这也顺带避开
  了第 4.5 节记录的"线段几何必须排在描边修复之后"这条依赖，这次不需要等）。
- **浮冰/冰川**：不可走区域里散布的独立几何块（棱角分明、低模），高度不一、
  朝向随机（用确定性伪随机种子摆放，不用真随机——与 `VegetationLayer` 现有
  的树木摆放同一套纪律，保证同一张地图每次加载画面一致、可复现）。
- **孤灵小岛**：比浮冰更大一圈的独立小岛，幽灵/亡灵主题装饰——墓碑（低模石碑
  剪影）、幽蓝鬼火（emissive 光点，同样要注意 3.3 节提到的描边排除问题）、
  飘散的灵魂光点。数量不多，稀疏散布，不要铺满整个水域（呼应第 5 节里
  "密度分区"的原则——重点氛围节点，不是均匀撒）。

## 4. 技术方案（内部实现，供参考，不是设计决策本身）

### 4.1 调色板架构：从"一张全局配色"扩展成"按地图取色"

现状：`CONFIG.stylizedVisuals` 是一份写死的全局配色（`demo_stylized_v1` 专用），
`map.visualStyle === 'stylized'` 是唯一开关，渲染代码直接读 `CONFIG.stylizedVisuals`。
如果嚎哭深渊冰封版也用这个开关，会跟 demo 撞色（拿到绿色调而不是冰蓝）。

**方案**：把 `CONFIG.stylizedVisuals` 扩展成按主题分组的字典（比如
`CONFIG.stylizedPalettes = { default: {...现在这些值...}, frost: {...新的冰封配色...} }`），
地图新增一个 `paletteId` 字段（`demo_stylized_v1` 不声明时退回 `'default'`，
逐位不变；嚎哭深渊风格化版声明 `paletteId: 'frost'`）。渲染代码从"直接读
`CONFIG.stylizedVisuals`"改成"读 `CONFIG.stylizedPalettes[map.paletteId || 'default']`"。
**这是一处必须改的现有代码**，但改动方式保证 `demo_stylized_v1` 的默认取值
和当前逐位一致（第 3 条铁律要求的"参数化默认值不变"）。

### 4.2 WallLayer 新增"贴边窄墙带"渲染模式

现状 `WallLayer.rebuild()` 只有两条分支：非风格化地图＝把整个不可走区域抬成
一整块 `WALL_H=70` 的台地；风格化地图（`visualStyle==='stylized'`）＝什么都
不画（早退）。**这两条都不是嚎哭深渊要的效果**——嚎哭深渊要"贴着桥边缘一条
窄墙"，桥外稍远处就该是水面高度（约等于 0），不是一整块抬高的台地。

需要新增第三条分支（初步命名 `wallStyle: 'edgeWall'`，具体命名到时候再定）：
只在"可走格与不可走格的边界"附近的若干格（比如 2~3 格宽，具体数值到时候
调）内生成崖面+顶面几何，超出这个宽度的不可走区域**不抬高**，留给第 3.5 节
的水面/浮冰渲染去接管。这是这次工作量最大的一块新代码，其它几项基本是配置
和摆放层面的工作。

### 4.3 TerrainLayer 的 navMode 分支需要补上 stylized 支持

读代码发现一个现有缺口：`buildTerrainLayer()` 的风格化配色只接在【走廊模型】
分支里（`demo_stylized_v1` 用的那条），navgrid 驱动的地图（`navMode` 分支）
现在**完全没有读 `stylized`/调色板**，路面颜色是写死的 `#2b3647`。这不是嚎哭
深渊专属的新需求，是现有风格化功能本来就没覆盖到 navgrid 地图这一类——这次
要把它补上，之后任何 navgrid 驱动的地图（包括以后召唤师峡谷/扭曲丛林的风格化
版本，它们大概率也是 navgrid）都能受益，不是嚎哭深渊单独绕一条路。
