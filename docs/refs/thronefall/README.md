## 从这批图里提取到的设计语言（详细版在设计文档里）

| 要素 | 规则 |
|---|---|
| 配色 | 每张图只有 2~4 个色相 + 一个深色阴影色；**地面亮、环境暗** |
| 阴影 | 单一方向、又长又硬、纯色无渐变——最强的风格标志 |
| 地形 | 大块平面多边形；**很亮的平顶 + 很暗的高侧面**，立体感全靠这一个装置 |
| 轮廓 | 长条、楔形、带尖角的不规则多边形；互相叠压出台地层次 |
| 植被 | 雪地＝尖锥松/冰刺，草地＝团块阔叶；形状只有一种，重复用 |
| 建筑 | 米白 + 深色墨线，是全场最亮最跳的东西（**塔是石头的，不是木头**） |
| 墙 | 低矮细长的一条带，规律细竖纹，间隔立粗柱，顶边细锯齿 |
| 边界 | 大块角面板层层叠压、向外后退，只用 3 档明度，不靠雾/渐隐 |
| 描边 | 有明显的深色描边，而且**挺重** |
