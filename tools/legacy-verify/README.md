# 历史验证脚本（存档，不再维护）

这些是早期开发时**一次性用完的验证脚手架**（每个文件头自己写着"临时脚手架，不入 tests/"），
从仓库根目录挪到这里。它们不是回归测试：

- 8 个里有 **7 个已经跑不起来**（依赖的模块签名早就变了）；
- `tests/run_all.mjs`、`package.json`、任何文档都**不引用**它们；
- 它们验证过的行为，现在都由 `tests/` 下的正式套件覆盖。

保留而不删除，是因为它们记录了"当初是怎么验的"——
比如 `verify_muzzle.mjs` 里那套"炮口高度取骨骼挂点"的验证思路，
以后动模型烘焙时还值得一读。

**不要往这里加新文件。** 新的验证一律写成 `tests/sim_*.mjs` 并注册进 `tests/run_all.mjs`；
一次性的探针写在 scratchpad 里，用完就扔，不要留在仓库中。
